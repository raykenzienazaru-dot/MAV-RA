# MAVÉRA

> **A Little Bite, A Lot of Happiness.**

Website pemesanan camilan manis & gurih MAVÉRA (SMAN 17 Jakarta).

## Fitur
- Katalog Menu (Manis & Gurih)
- Pencarian dan Filter Kategori Menu
- Keranjang Belanja Interaktif
- Pemesanan Langsung via WhatsApp

## Struktur File
- index.html: Struktur halaman web utama
- style.css: Berkas stylesheet CSS
- script.js: Berkas logika JavaScript & data menu
